Privacy Policy

Threads Reply Finder · Effective date: November 8, 2026

Threads Reply Finder (“the App”) is a personal research tool operated by an individual developer (“we”, “us”). It helps its operator find public Threads posts in which people ask for product recommendations, so the operator can read them and decide whether to reply personally in the Threads app. This policy explains what data the App accesses through the Threads API and how that data is handled.

1. Data We Access

Authenticated account (threads_basic)

  • The Threads user ID and username of the account that authorizes the App.
  • Used only to show which account is connected and to exclude that account's own posts from search results.

Public posts (threads_keyword_search)

  • For public posts that match keywords chosen by the operator: post ID, text, media type, permalink, publish time, and the author's public username.
  • We do not access private profiles, direct messages, follower lists, email addresses, phone numbers, or any other non-public information.

2. How We Use the Data

  • To display matching posts in a private dashboard that only the operator can see.
  • To estimate whether a post is asking for a recommendation, using simple text rules.
  • To produce aggregate statistics, such as which topics are asked about most often.

The App does not post, reply, like, follow, or send messages automatically. Any reply is written and sent manually by the operator in the Threads app. We do not use the data for advertising, profiling, or training machine learning models.

3. Storage and Security

  • Data is stored only in a local database on the operator's own computer. It is not uploaded to any server or cloud service operated by us.
  • Access tokens are stored locally and are never shared.
  • Post data is kept for no more than 90 days after it is retrieved and is then deleted automatically.

4. Sharing

We do not sell, rent, share, or disclose any data obtained from the Threads API to any third party. The only external service the App communicates with is the Threads API provided by Meta Platforms, Inc., whose own policies apply to that communication.

5. Children

The App is not directed to children and is not intended for use by anyone under the age required to use Threads.

6. Your Choices and Rights

  • You can delete or restrict the visibility of your own Threads posts at any time in the Threads app; the App only accesses posts that are public at the time of searching.
  • You can ask us to delete any data related to you. See Data Deletion below.

7. Changes to This Policy

We may update this policy from time to time. The effective date at the top of this page shows when it was last updated.

8. Contact

隱私權政策

Threads Reply Finder（Threads 回覆機會雷達）・生效日期：2026 年 11 月 8 日

Threads Reply Finder（以下稱「本程式」）是由個人開發者（以下稱「我們」）經營的個人研究工具， 用來找出 Threads 上詢問商品推薦的公開貼文，讓使用者閱讀後自行決定是否在 Threads App 中親自回覆。 本政策說明本程式透過 Threads API 存取哪些資料，以及這些資料的處理方式。

一、我們存取的資料

授權帳號（threads_basic）

  • 授權本程式之 Threads 帳號的使用者 ID 與使用者名稱。
  • 僅用於顯示目前連結的帳號，以及在搜尋結果中排除該帳號自己的貼文。

公開貼文（threads_keyword_search）

  • 符合使用者所設定關鍵字的公開貼文之：貼文 ID、內文、媒體類型、貼文連結、發布時間、作者的公開使用者名稱。
  • 我們不會存取非公開帳號、私訊、追蹤者名單、電子郵件、電話號碼或任何其他非公開資訊。

二、資料用途

  • 在僅限使用者本人可見的介面中列出相關貼文。
  • 以簡單的文字規則判斷貼文是否在詢問推薦。
  • 產生彙總統計，例如哪些主題最常被詢問。

本程式不會自動發文、回覆、按讚、追蹤或傳送訊息。所有回覆皆由使用者在 Threads App 中手動撰寫並送出。 我們不會將資料用於廣告、建立個人檔案或訓練機器學習模型。

三、儲存與安全

  • 資料僅儲存在使用者本人電腦上的本機資料庫，不會上傳至我們經營的任何伺服器或雲端服務。
  • 存取權杖（access token）僅儲存於本機，不會提供給任何人。
  • 貼文資料自取得起最多保存 90 天，期滿後自動刪除。

四、資料分享

我們不會出售、出租、分享或揭露任何透過 Threads API 取得的資料給第三方。 本程式唯一連線的外部服務是 Meta Platforms, Inc. 提供的 Threads API，該連線適用 Meta 的相關政策。

五、兒童

本程式並非以兒童為對象，也不適用於未達 Threads 使用年齡規定的人士。

六、您的選擇與權利

  • 您可以隨時在 Threads App 中刪除自己的貼文或調整其公開範圍；本程式只會存取搜尋當下為公開的貼文。
  • 您可以要求我們刪除與您相關的任何資料，方式請見下方「資料刪除」。

七、政策變更

我們可能不定期更新本政策，最新的生效日期會顯示於本頁上方。

八、聯絡方式

如對本政策有任何疑問，請來信：[CONTACT_EMAIL]

Data Deletion Instructions / 資料刪除說明

To request deletion of any data related to you:

  1. Send an email to [CONTACT_EMAIL] with the subject “Data Deletion Request”.
  2. Include your Threads username and, if possible, links to the related posts.
  3. We will delete all related data within 30 days and confirm by email.

If you authorized the App with your own Threads account, you can also revoke access at any time in Threads: Settings → Account → Website permissions → Active → remove the App.

如需刪除與您相關的資料：

  1. 寄信至 [CONTACT_EMAIL]，主旨請註明「資料刪除申請」。
  2. 信中請提供您的 Threads 使用者名稱，可以的話附上相關貼文連結。
  3. 我們會在 30 天內刪除所有相關資料，並以電子郵件回覆確認。

若您曾以自己的 Threads 帳號授權本程式，也可以隨時在 Threads 中撤銷：設定 → 帳號 → 網站權限 → 使用中 → 移除本程式。
